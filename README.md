# mcp-tool-schema-patcher

Repairs MCP tool schemas generated by `mcp-annotations` for Spring AI 1.1.x.

## Patchers

| Patcher | Purpose | Maven Central |
|---------|---------|---------------|
| [`ToolSchemaDefsPatcher.patch(specifications)`](mcp-tool-schema-patcher-core/README.md) | Repairs input schema definition references for Java and Kotlin tools. | [Core](https://central.sonatype.com/artifact/io.github.xu-justin/mcp-tool-schema-patcher-core) |
| [`ToolSchemaNullabilityPatcher.patch(toolObjects, specifications)`](mcp-tool-schema-patcher-kotlin/README.md) | Repairs Kotlin schema nullability. Java tools are returned unchanged. | [Kotlin](https://central.sonatype.com/artifact/io.github.xu-justin/mcp-tool-schema-patcher-kotlin) |

## Usage

The Kotlin module includes core as a dependency:

```kotlin
dependencies {
  implementation("io.github.xu-justin:mcp-tool-schema-patcher-kotlin:<version>")
}
```

```kotlin
import io.github.xujustin.mcpschema.ToolSchemaDefsPatcher
import io.github.xujustin.mcpschema.ToolSchemaNullabilityPatcher
import org.springaicommunity.mcp.provider.tool.SyncStatelessMcpToolProvider

val toolObjects = listOf(MyTools())
val provider = SyncStatelessMcpToolProvider(toolObjects)
val referencesPatched = ToolSchemaDefsPatcher.patch(provider.toolSpecifications)
val specs = ToolSchemaNullabilityPatcher.patch(toolObjects, referencesPatched)
// Pass specs to the server builder's .tools(specs).
```

For input references only, use the core module and `ToolSchemaDefsPatcher`.
See each module's README for examples, compatibility, and upstream fix details.

Requires Java 17+. Targets Spring Boot 3.5.x and Spring AI 1.1.x.

## Build

```sh
./gradlew clean build generatePomFileForMavenPublication
```

Builds the modules, runs tests, and generates coverage reports, sources, API documentation,
and Maven POMs. CI runs the same checks on Java 17 and 21.
