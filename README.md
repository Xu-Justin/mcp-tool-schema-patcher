# mcp-tool-schema-patcher

Repairs MCP tool schemas generated by `mcp-annotations` for Spring AI 1.1.x.

## Why do we need this?

Generated schemas can contain unresolved input references or lose Kotlin nullability information.
Clients may reject these schemas or reject valid tool arguments and results.

## How do we solve this?

The library provides two patchers that preserve the original specifications, tool metadata,
and call handlers.

| Module | Purpose |
|--------|---------|
| [Core](mcp-tool-schema-patcher-core/README.md) | Repairs input schema definition references for Java and Kotlin tools. |
| [Kotlin](mcp-tool-schema-patcher-kotlin/README.md) | Repairs Kotlin schema nullability. Java tools are returned unchanged. |

## Usage

See each module's README for installation, examples, compatibility, and upstream fix details.
The Kotlin module includes core as a dependency; each patcher is called explicitly.

Requires Java 17+. Targets Spring Boot 3.5.x and Spring AI 1.1.x.

## Build

```sh
./gradlew clean build generatePomFileForMavenPublication
```

Builds the modules, runs tests, and generates coverage reports, sources, API documentation,
and Maven POMs. CI runs the same checks on Java 17 and 21.
